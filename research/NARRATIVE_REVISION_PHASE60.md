# Phase 60 narrative revision after 60D2

This file records the post-test revision of the frozen narrative in `NARRATIVE_HYPOTHESIS_PHASE60.md`. The original is intentionally preserved unchanged so that predictions cannot be rewritten after seeing results.

## What survived

Phase60A-60C support a manuscript-wide paragraph-entry formal role:

- genuine paragraph starts differ from matched internal pseudo-boundaries;
- the difference is carried by a stable subset of structural features rather than diffuse estimator noise;
- entry/body distinctions transfer across held-out H/B/P/S/T sections beyond simple nuisance structure;
- medieval structured-document entries explain part, but not all, of the Voynich transition.

The surviving compact description is:

> Voynich paragraph starts instantiate a transferable, short-lived entry register/formal role, partly homologous to generic medieval item/section-entry grammar and partly specialized in Voynichese.

## What failed

The stronger claim that the entry line initializes a persistent paragraph state did not survive the prospective test.

Phase60D initially found strong predictability of a line2-line0 recovery vector from line0, but that target algebraically contains line0 and is vulnerable to mathematical coupling/regression to the mean.

Phase60D2 removes that problem by predicting absolute line3 state after line1 is already known. Adding the actual line0 does not improve held-out prediction; it worsens prediction in every major section.

Therefore withdraw:

> entry line carries persistent state information that controls or predicts the later paragraph body.

Do not cite Phase60D as evidence for that claim.

## Revised narrative N60-R1

The manuscript uses a highly constrained writing system with a special paragraph/item-entry register. The writer changes formal token-family, edge-pattern, length/diversity and near-family behavior at paragraph onset, then transitions rapidly toward ordinary body-state behavior.

The evidence currently supports a **boundary/register switch** more strongly than a **persistent initialization state**.

This is compatible with at least four mechanism families:

1. meaningful structured text with conventional or specialized entry forms;
2. cipher/shorthand in which paragraph onset invokes special surface conventions but not a long-lived detectable state;
3. hierarchical nonsemantic generation with explicit paragraph-entry machinery;
4. deliberate pseudo-text engineered to imitate structured manuscript entries, provided an executable bounded rule can reproduce the joint evidence.

No semantic family currently receives preference from the Phase60 structural tests alone.

## New discriminating question

The next question is not "what does the entry initialize?" but:

> What is the minimum mechanism required to generate the observed short-lived entry-register signature while simultaneously preserving Voynich token morphology, local family activation, line grammar, section transfer and medieval-entry partial homology?

This is the target for Phase60E.

## Rules for Phase60E

- Estimate the entry memory horizon using prospective absolute-state tests without algebraic coupling.
- Compare joint structural fit, not a single reset scalar.
- Begin with stationary/weak-context generators before granting explicit entry state.
- Charge added entry machinery as model complexity.
- Apply bounded cipher transforms to independently sourced structured medieval controls using the same frozen metrics.
- A generator/cipher is not supported merely because it can be tuned to one observed statistic.
- Meaning-bearing interpretations still require independent content prediction.
