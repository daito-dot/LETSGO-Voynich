# Token-construction program — purpose, object, and decision path

Status: normative orientation for the current token-construction research lane.

This document exists so that a future researcher or agent can recover **why this lane is being run** before reading the individual statistical tests. Phase-specific frozen plans, first-reveal artifacts, and reports remain authoritative for exact methods and numerical results.

## One-sentence purpose

> Determine whether Voynich **space-delimited tokens** are generated by a constrained internal construction system, and whether the non-trivial part of that system is shared across the manuscript or changes by register/section/position.

## What the object is

The object is **not sentence grammar** and it is not yet a claim about natural-language words.

We use `space-delimited token` deliberately because the manuscript's visible spaces have not been established as natural-language word boundaries.

For the current representation, a parsed token is described through a frozen 12-slot construction. Each slot can be occupied or empty. The present lane asks about dependencies among those occupancy decisions:

- which slots tend to co-occur;
- which slots tend to exclude one another;
- which dependencies remain after controlling for simpler occupancy structure;
- whether the same residual dependency system appears in different manuscript strata.

A relation such as `slot3 occupied -> slot5 unusually absent` is therefore a **token-internal construction constraint**. It is not, by itself, a meaning assignment, a plaintext letter relation, or a cipher table.

## Why this matters to decipherment

The immediate statistical target is narrow, but the scientific reason for testing it is broader.

If a stable non-trivial token-internal construction system survives across Currier/register/section and line position, then future decoding/generative models should explain a **common surface-generation mechanism** before being treated as viable manuscript-wide accounts.

If the residual construction system changes materially across strata, then treating all Voynich tokens as outputs of one uniform generator is likely wrong. Later inverse/decoding work should instead use a hierarchical or multiple-generator model.

Thus this lane is partly answering a prerequisite question:

> **How many token-generation systems are we trying to invert?**

This still does not establish whether the underlying information is natural language, ciphered text, artificial text, or another structured source.

## What has been established so far

### Issue #55

A selected slot3×slot5 relation was real, but #55B showed that essentially all of the measured dependence reduced to the binary fact that the two slots are almost never occupied together.

This established a genuine token-internal occupancy constraint, not a semantic interpretation.

### Issue #58A

The selection-aware complete-graph audit tested all `C(12,2)=66` slot pairs rather than privileging slot3×slot5.

Frozen result:

> `BROAD OCCUPANCY GRAMMAR; SLOT3xSLOT5 NOT UNIQUE`

Twenty-two edges qualified under the frozen family-wise primary rule. The graph contains both strong co-occurrence and strong exclusion. Therefore the research object moved from one selected pair to the **complete signed occupancy graph**.

### Issue #58B

The next question was whether the complete signed graph is shared across externally defined manuscript strata.

Observed full-graph similarities were numerically high, with strong within-stratum reliability and generally strong cross-stratum transfer. However, the frozen line-local marginal-preserving null itself produced extremely high complete-graph correlations (`median maxT ≈ 0.949`). None of the seven planned similarities was family-wise exceptional at the preregistered threshold.

Frozen global classifications:

> `CURRIER/SECTION GRAPH STABILITY INCONCLUSIVE`

> `LINE-POSITION GRAPH STABILITY INCONCLUSIVE`

This does **not** show that the strata are different. It also does **not** establish a shared deep grammar. It shows that raw complete-graph similarity is strongly dominated by structure that survives the null — especially slot prevalence / line-local occupancy architecture.

## Current working interpretation

There is strong evidence that the 12-slot representation is not freely combinatorial: space-delimited tokens have substantial internal construction structure.

The unresolved question is more specific:

> After removing the similarity expected from slot prevalence and line-local occupancy architecture, is there a reproducible **excess / residual interaction graph** that is shared across manuscript strata?

This is now the central token-construction question.

## Next scientific move

Do **not** simply correlate the same raw 66-edge graphs again with a different threshold.

The next phase should be plan-first and should separate two questions:

1. **Residual existence:** after centering/standardizing each edge against an independently estimated line-local null expectation, is there graph-level residual interaction mass beyond that null?
2. **Residual transfer:** if such residual structure exists, does its signed pattern transfer across predeclared Currier/section/position strata better than independently transformed null graphs?

To avoid using the same null realizations both to define and to validate the residual representation, freeze separate deterministic reference-null and test-null sets before reveal (for example 1,000 + 1,000 permutations). The reference set estimates edge-wise null expectation/scale; the test set supplies the independent graph-level null distribution and multiplicity control.

The residual graph should not be interpreted if the residual-existence gate fails.

## Decision path

### Residual graph exists and transfers across strata

Promote a manuscript-wide token-construction mechanism as a strong surface constraint. Then test representation/transcription invariance and use the stable constraints prospectively to restrict reversible generative/inverse models.

### Residual graph exists but differs across strata

Move to a hierarchical token-construction model: shared baseline plus register/section/position-specific interactions, or multiple generators if warranted.

### No graph-level residual survives

Conclude that much of the current 66-edge graph can be explained by lower-order occupancy architecture under the tested representation. Do not continue treating the raw signed graph as a deep manuscript-wide grammar. Return to a different structural representation or a different independently motivated inverse constraint.

### Residual result is underpowered/inconclusive

Record the support limitation. Do not rescue the claim by selecting the visually strongest #58A/#58B edges after reveal.

## Interpretation boundaries

This lane must not silently become any of the following:

- a proof that spaces are true word boundaries;
- sentence-level syntax analysis;
- semantic assignment to slots;
- a plaintext alphabet or cipher-table inference;
- evidence for or against all ciphers;
- evidence that the manuscript is meaningless;
- a revival of the music/Sloane interpretation that historically exposed one residual;
- decipherment.
