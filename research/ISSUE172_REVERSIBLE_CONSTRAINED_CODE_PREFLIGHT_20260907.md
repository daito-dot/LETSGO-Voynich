## Question

> Does the already-frozen 12-slot Voynich surface language have enough injective combinatorial capacity to carry arbitrary information reversibly, before any attempt is made to match the empirical G7A/V2 probability law or the cross-token responsibilities?

This is deliberately narrower than a cipher hypothesis.

A positive result would establish only that strong token-internal grammatical constraints and exact information recovery are mathematically compatible. It would not show that the manuscript was encoded this way, that the empirical token distribution is reproduced, or that any cross-token responsibility is explained.

## Why this control is needed

The current #172 R2 gate is a `FROZEN_ADAPTER`: candidate surface strings are parsed by the immutable 12-slot `SlotParser(min)` representation. Historical ciphers with arbitrary glyph alphabets are therefore not R2-comparable until they also specify a Voynich-surface emission layer.

Two previous controls bracket, but do not answer, the present question:

- **C0-4** is exactly structured-reversible, but its output atoms are opaque length-delimited transformed source units, not an EVA/12-slot surface. It was explicitly retained as a reversibility control rather than an R2 surface candidate.
- **OGH-C V2** is a compact complete memoryless Voynich token generator (about 9.71 bits/token cross-entropy) and inherits the R2-compatible token construction grammar, but it was sampled as a generator rather than used as an information-lossless encoder.

RC-A0 tests the missing intersection: reversible information transport **inside** the frozen surface language.

## External mathematical motivation

Constrained coding is an established information-theoretic problem: encode unconstrained information into sequences generated by a finite-state constraint while retaining a decoder. Standard finite-state/state-splitting and enumerative constructions establish lossless encoders below the capacity of a constrained system.

References:

- Brian H. Marcus, Ron M. Roth, Paul H. Siegel, *An Introduction to Coding for Constrained Systems*, especially capacity, finite-state encoders and state-splitting: https://cmrr-star.ucsd.edu/psiegel/book_draft/
- Jonathan J. Ashley, Brian H. Marcus, Ron M. Roth, *Construction of Encoders with Small Decoding Look-Ahead for Input-Constrained Channels*, IEEE Transactions on Information Theory (1995): https://research.ibm.com/publications/construction-of-encoders-with-small-decoding-look-ahead-for-input-constrained-channels

RC-A0 is therefore a standard mathematical architecture whose **constraint set** is target-derived. That distinction is recorded under R10.

## S0 exact surface language

For each of the 12 slots, choose either:

- ABSENT; or
- exactly one value from the slot's frozen value set.

Concatenate selected values in increasing slot order. Exclude the all-ABSENT sequence.

The raw structural-path count is therefore fixed analytically as:

`N_paths = product_s (1 + |SLOTS[s]|) - 1`.

Different structural paths may collapse to the same literal surface string because values such as `d`, `s`, `o`, `l`, `r` and `y` occur in multiple slots. S0 must therefore enumerate the full path set and count **distinct literal surface strings** rather than treating path count as code capacity.

No observed Voynich token is privileged or looked up.

## Deterministic codebook

Let `U` be the sorted set of all distinct non-empty surface strings generated by the frozen slot language.

Define:

`k = floor(log2(|U|))`.

For a fixed-block code at rate `k bits / token`, use exactly the first `2^k` strings of `U` in Python Unicode/code-point lexicographic order. Integer `i` maps to codeword `U[i]`; decoding is the inverse rank in the same deterministic generated set.

This is a mathematical codebook generated from the frozen constraint, not an empirical Voynich vocabulary lookup table.

For practical exhaustive round-trip checking, S0 additionally freezes a 16-bit view when available:

- if `|U| >= 65536`, the `S0-16` codebook is the first 65,536 strings;
- encode every integer 0..65,535 and decode it exactly;
- every codeword must be accepted by `SlotParser(min)`.

If 16-bit support is unavailable but `|U| >= 256`, an 8-bit exhaustive view is permitted only as the predeclared lower class below; no threshold is changed after reveal.

## S0 outputs allowed

S0 may report only:

- slot cardinalities;
- `N_paths`;
- number of distinct literal surface strings `|U|`;
- collision count `N_paths - |U|`;
- fraction of distinct strings with multiple structural parses;
- `floor(log2 |U|)`;
- token-length distribution of the abstract language;
- exhaustive S0-16 or S0-8 encode/decode closure;
- parser acceptance of the deterministic codebook;
- SHA-256 of the generated codebook audit/result.

It must set and assert:

- `voynich_corpus_accessed = false`;
- `g7a_v2_probabilities_accessed = false`;
- `r1_r8_scientific_score_computed = false`.

## S0 frozen classes

1. `S0_CAPACITY_16PLUS_EXACT`
   - `|U| >= 65536`;
   - exhaustive 16-bit round trip 65,536/65,536;
   - parser acceptance 65,536/65,536.

2. `S0_CAPACITY_8_TO_15_EXACT`
   - `256 <= |U| < 65536`;

   - parser acceptance 256/256.

3. `S0_INSUFFICIENT_BYTE_CAPACITY`
   - `|U| < 256`.

4. `S0_INVALID`
   - enumerator/path-count invariant, deterministic ranking, parser acceptance or round-trip audit fails.

## Interpretation firewall

A positive S0 is **not** an R2 PASS.

It establishes only exact reversible capacity in the *support* of the frozen adapter. Uniformly using the lexicographic codebook will generally not reproduce the empirical G7A/V2 occupancy/value distribution and must not be scored as if it did.

It also says nothing about R1, R3, R4, R5, R6, R7 or R8.

## Conditional S1 — distribution matching, not yet licensed

Only if S0 is exact may a separate S1 plan be frozen.

S1 would ask a stronger mathematical question:

> Can an information-lossless distribution matcher map external compressed plaintext bits into sequences whose token distribution follows a frozen G7A/V2 grammar closely enough to retain the complete-66 R2 topology?

S1 must freeze before any new R2 score:

- the exact distribution-matching construction and finite block length;
- external plaintext and compression;
- target-derived probability access cost;
- decoder closure;
- treatment of cross-fitted grammars versus one global grammar;
- approximation/error bound to the requested output distribution;
- all stochastic seeds if any.

S1 remains an upper-bound control. Because it is explicitly given the Voynich-derived grammar, a positive R2 result cannot be used as evidence that the historical mechanism was discovered.
