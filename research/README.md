# Research directory — authority map

This directory contains both current scientific authority and historical records. Use this index to avoid treating an old addendum or checkpoint as the latest state.

## Current authority

Read these as the maintained current layer:

- `STATUS.md` — current accepted high-level interpretation;
- `HYPOTHESIS_LEDGER.md` — current hypothesis status, including negative results;
- `PREDICTIVE_INFORMATION_PROGRAM.md` — Issue #88 program and latent-state licensing rule;
- `RESEARCH_PROTOCOL.md` — normative evidential discipline;
- `RESEARCH_OBJECTIVE.md` — program purpose;
- `TOKEN_CONSTRUCTION_PROGRAM.md` — token-construction lane purpose/limits where still relevant.

Current sequencing and restart instructions live at repository root:

- `../RESUME.md`;
- `../ROADMAP.md`.

## Historical authority

Exact historical claims are controlled by their phase/Issue-specific materials, usually under `experiments/`:

1. frozen plan;
2. committed scientific scorer/harness;
3. first successful reveal artifact/provenance;
4. report/classification.

A later consolidated status may narrow interpretation without rewriting a frozen historical pass/fail decision.

## Archive

`archive/` contains superseded navigation/current-state snapshots that are useful for provenance but must not be used as current instructions.

Examples include old `RESUME`, `ROADMAP`, `NEXT_RESEARCH_FRONTIER`, root research-protocol snapshots and the legacy lowercase hypothesis ledger.

## Addenda policy

Files named `HYPOTHESIS_LEDGER_ADDENDUM_*`, `*_ADDENDUM_*`, or similar are **historical records**, not parallel current ledgers.

They remain in place when old Issues/reports link to them. New accepted conclusions should be merged into `STATUS.md` and `HYPOTHESIS_LEDGER.md` rather than creating another current-state addendum.

If a new phase needs a frozen pre-reveal contract, put that contract with the experiment/Issue materials rather than in a new status addendum.

## Naming policy going forward

- one current status: `STATUS.md`;
- one current hypothesis ledger: `HYPOTHESIS_LEDGER.md`;
- one current restart point: root `RESUME.md`;
- one current sequencing map: root `ROADMAP.md`;
- one normative research protocol: `RESEARCH_PROTOCOL.md` in this directory;
- superseded navigation snapshots go to `archive/` with a date/issue suffix.

Do not create case-only duplicates such as `hypothesis-ledger.md` beside `HYPOTHESIS_LEDGER.md`.

## Interpretation firewall

Keep these levels separate in every new document:

1. descriptive/structural result;
2. predictive/model result;
3. historical mechanism;
4. content relation;
5. decipherment.

A successful surface generator or predictor is not automatically a historical mechanism or decoder.
