# 研究チェックポイント（日本語）

## 現在どこまで分かったか

Voynicheseには、語内部の強い位置制約、行内位置による違い、folio/section差、局所的な語形family、段落境界での状態変化がある。ここまではかなり強い。

一方で、それが

- 意味を持つ自然言語
- 情報を保存した暗号
- 意図的に解読を難しくした暗号
- 意味を必須としない形式生成
- それらの混合

のどれなのかを決める情報保存則はまだ得られていない。

重要なのは、**構造的に同じ役割を持つことと、同じ平文値を表すことは別**という点である。

## これまでに強くなったこと

- `{k,t}` は構造的equivalence候補として強い。ただし暗号的同値とは言えない。
- tokenの値を捨ててもslot occupancyだけで文書役割や行位置の情報が残る。
- 近縁token familyは局所的にまとまる。
- 段落境界では、直前行とのedit-distance-1 family共有が大きく落ちる。
- その段落resetは語頭だけではなく、語中・語末、置換・挿入・削除に広く分布する。
- Voynich内部でもsectionによって特徴量がかなり動く。

## 弱くなった／棄却したもの

- Pharma画像対応から植物名を直接拾う現在の方法は支持されない。
- 単純な4周期・数値周期解釈は強いnullで消える。
- 文字列が似ているから直前の語をcopy-and-modifyしている、という単純な逐次コピー説は弱くなった。
- 短期的な連続性そのものは中世Latin散文にも強く存在するため、Voynich固有の証拠ではない。
- Phase50でVoynichに近づけた単純finite-state DSLは、freeze後に段落resetと行位置grammarで大きく失敗した。十分な全体機構ではない。

## 現在の重要な問い

### 1. 文書ジャンル交絡

Dante一冊をLatin代表にすることはできない。同じ中世Latinでも、医学・文学・スコラ学・教会文書などで近縁語形密度や行位置効果が大きく動くことがPhase52 pilotで確認された。

したがって次は「言語」だけでなく、

`個別文書 → ジャンル → 言語`

の階層を分離する。

特にVoynichに近い可能性がある医学、レシピ、薬学的列挙、注釈・スコラ学、強い定型文書を重点的に比較する。

### 2. 段落resetの正体

現在もっとも面白い識別対象の一つ。単なる短期記憶ではなく、段落境界でactive token familyのrepertoireが広く切り替わる。

これは自然言語の話題・項目切替でも、cipher state/key切替でも、形式生成器のparagraph state resetでも説明可能なので、対照文書を増やす必要がある。

### 3. 次の形式生成器

Phase52で文書ジャンル交絡を確認した後、最小の階層生成器を比較する予定：

- M0: Phase50の単純DSL
- M1: M0 + line-position mechanism
- M2: M0 + paragraph reset/state
- M3: M0 + line + paragraph hierarchy

追加機構はPhase51の失敗を見てから追加するので、複雑度コストを払わせる。評価にはpredictive code length / MDLを使う。

## 解読と呼ぶための基準

読めそうな一文が出ただけでは不十分。

少なくとも、

- 実行可能な固定mapping/generation rule
- 十分量の未見データ予測
- 解釈可能な固定出力
- 強いnull/競合モデルとの比較
- prospectiveまたはexternal replication
- 失敗例・例外の明示

が必要。

## 公開研究方針

このGitHubは「解読済み」を宣言する場所ではなく、世界中から解読法・暗号説・言語説・生成説を募り、同じ反証可能性と再現性の基準で検証する場所にする。
