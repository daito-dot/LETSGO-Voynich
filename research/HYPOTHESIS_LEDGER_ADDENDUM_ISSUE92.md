## P88-1 — the conspicuous cross-token structure is nearly exhausted by a small <=40-token local mechanism

**State before Phase 1:** LIVE.

**Frozen test:** compare the Phase-0 bounded local DECAY40 anchor with prospectively richer history and observable-state predictors using nested/outer held-out literal-surface likelihood only.

**Result:** **REJECTED under the tested predictive ladder.**

- B1 local gain over V2: `0.112725 bit/token`, positive 5/5 folds.
- B2 longer-history increment over B1: `0.046927 bit/token`, positive 5/5.
- B3 observable paragraph/line-state increment over B2: `0.028929 bit/token`, positive 5/5.

The tested predictive budget therefore contains reproducible structure beyond <=40-token local recency.

## P88-2 — the Phase-1 long-history gain establishes a literal leaf-long historical memory process

**State:** **NOT LICENSED.**

All five B2 selectors choose all preceding tokens on the current physical leaf, `tau=128`, `pi=.30`. But history extent and mixture strength are grid boundaries, and the mechanism can exploit the accumulating causal prefix inventory even without a historically literal long-memory state.

Required next test: Issue #94 Phase 2A must separate actual order/lag information from causal prefix token-family inventory using prefix-bag and matched random-lag controls.

## P88-3 — visible document-production position carries predictive information beyond token history

**State:** **SUPPORTED under the tested representations.**

B3 adds `0.028929 bit/token` in 5/5 folds after B2. Every selector uses `lambda=.50`, but the preferred representation varies (`ENTRY_BODY` 2 folds; `LINE4` 3 folds).

Thus visible paragraph/line geometry is predictively informative; one uniquely correct positional state representation is not established.

This is not a semantic state claim.

## P88-4 — cross-token predictability is an artifact of the V2/edit-distance representation

**State:** **WEAKENED.**

A separate UTF-8 byte n-gram family shows lower held-out code length when context crosses visible-space boundaries than when the same model family resets context at every token:

- matched cross-boundary gain `0.129645 bit/token`;
- positive in 5/5 folds.

However the flexible byte model does not prospectively establish more cross-token information than the simple DECAY40 family: `Delta_flex_over_local` is positive only 3/5 folds and fails the frozen stability rule.

## P88-5 — several hidden bits/token of sentence-like structure are already demonstrated

**State:** **REJECTED as a reading of current evidence.**

The explicit V2-based ladder reduces held-out code length by about `0.188582 bit/token` from B0 to B3, roughly 1.94% of the ~9.71-bit memoryless token code. This is materially non-zero but far below the previously abandoned intuition of `2–3 bits/token` from local recurrence.

No unrestricted entropy bound has been measured.

## Program consequence

The current frontier is **source attribution, not latent-state fitting**.

First determine whether the B2 long-history increment is primarily:

- order-sensitive sequence information;
- causal prefix / leaf token-family inventory;
- observable document-state heterogeneity;
- or a mixture.

Only a residual that survives those controls can strengthen the case for an unobserved state or external-input mechanism.
