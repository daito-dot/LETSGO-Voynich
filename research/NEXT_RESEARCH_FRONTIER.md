# Next research frontier — residual token-construction graph

Status: next plan-first frontier after Issue #58B first reveal and integration.

## Program-level purpose

Read `research/TOKEN_CONSTRUCTION_PROGRAM.md` first.

The object is **one space-delimited Voynich token**, not sentence-level grammar. Visible spaces are observed delimiters, not assumed natural-language word boundaries.

The broader decision we need is:

> **Is there one non-trivial internal token-generation system operating across the manuscript, or does a later inverse/decoding model need multiple/hierarchical token generators?**

## Why the frontier moves here

Issue #55 found a real slot3×slot5 dependence and reduced it to binary occupancy exclusion.

Issue #58A then removed selection bias by scoring the complete frozen 12-slot binary occupancy graph. It found a broad signed network of co-construction and exclusion relations rather than a unique slot3×slot5 key.

Frozen #58A classification:

> `BROAD OCCUPANCY GRAMMAR; SLOT3xSLOT5 NOT UNIQUE`

Issue #58B then tested whether the complete signed graph is stable across externally defined Currier/section/line-position strata using all 66 edges, physical-leaf held-out transfer, `K_other` conditioning and 1,000 line-local slot-occupancy relocation nulls.

The observed graphs were highly reliable and mostly highly correlated, but the null itself generated whole-graph correlations near the same range. Null maxT median was approximately `0.949`, and none of the seven planned real similarities reached family-wise `p_maxT <= .01`.

At the same time, no contrast met the frozen practical difference gates.

Frozen #58B classifications:

> `CURRIER/SECTION GRAPH STABILITY INCONCLUSIVE`

> `LINE-POSITION GRAPH STABILITY INCONCLUSIVE`

Therefore the blocker is not simply low observed similarity. The blocker is that **raw complete-graph similarity is not discriminating enough against lower-order line-local occupancy architecture**.

## Primary new question

> After removing the edge-wise association expected from the exact line-local occupancy null, does a graph-level **residual/excess interaction signal** remain in real Voynich tokens?

Only if that first question is answered positively should the phase ask:

> Is the signed residual interaction pattern stable across the already source-grounded Currier/section/line-position strata?

This ordering is essential. A stable-looking residual vector is not scientifically meaningful if the residual vector itself is not stronger than an independent null.

## New-hypothesis status

This frontier is a **new hypothesis generated by the #58B result**.

It must not be described as a repaired or continued confirmatory version of #58B. #58B remains frozen and inconclusive.

## Required design before any target reveal

### 1. Keep the complete graph

Use all 66 unordered slot pairs as the primary graph object. Do not select `(8,10)`, `(3,5)` or other observed leaders for confirmatory testing.

### 2. Preserve the established representation unless changed prospectively

Default:

- same frozen 12-slot parser;
- parser `min` primary;
- parser `max` non-promoting sensitivity;
- same source commit/blob;
- same five physical-leaf folds;
- same externally defined target strata from #58B.

Any change requires an explicit pre-reveal justification and cannot be chosen by looking at residual outcomes.

### 3. Define an edge-wise null residual prospectively

For each stratum and edge, estimate the expected conditional Yule-Q value under the same line-local occupancy relocation mechanism that exposed #58B's high similarity baseline.

A candidate family is:

`Z_e = (Q_real,e - center_null,e) / scale_null,e`

where center and scale are estimated only from a frozen **reference-null** ensemble.

The exact center estimator, scale estimator, clipping/winsorization rule if any, sparse-edge treatment, and minimum-scale floor must be frozen before target scoring.

No post-reveal choice between mean/median, SD/MAD, raw delta/Z-score, etc.

### 4. Separate null estimation from null validation

Do not use the same simulated populations both to define the residual transformation and to claim that the transformed real graph is exceptional.

Preferred structure:

- deterministic **reference-null ensemble** — e.g. 1,000 nulls — estimates edge-wise center/scale;
- independent deterministic **test-null ensemble** — e.g. another 1,000 nulls — is transformed using reference parameters and supplies the null distribution for graph-level tests.

The exact counts/seeds must be frozen in the plan.

### 5. Residual-existence gate comes first

Before cross-stratum interpretation, define a graph-level statistic measuring whether the real residual graph contains more structured interaction mass than test-null graphs.

Candidate families include a robust norm or cross-fold reproducible norm over the full 66-edge vector. Exact statistic and threshold must be frozen before reveal.

A valid existence test should avoid being trivially inflated by one extreme edge and should retain sign information where scientifically relevant.

If the residual-existence gate fails, stop. Do not interpret residual graph correlations.

### 6. Residual stability/transfer gate comes second

If residual existence survives, compare complete residual graph vectors across the same planned contrasts:

- Currier A vs B within Herbal;
- section B vs H within Currier B;
- section B vs S within Currier B;
- section H vs S within Currier B;
- initial vs interior;
- initial vs final;
- interior vs final.

Use physical-leaf held-out transfer and independent test-null family-wise correction.

### 7. Freeze global decision branches

The plan must distinguish at least:

#### `SHARED RESIDUAL TOKEN-CONSTRUCTION GRAPH`

A non-null residual graph exists and transfers across all required manuscript strata under frozen support criteria.

#### `RESIDUAL GRAPH EXISTS WITH STRATUM MODULATION`

A non-null residual graph exists, but prospectively defined deviations/transfer loss show limited register/section/position modulation.

#### `MULTIPLE/HIERARCHICAL RESIDUAL TOKEN GRAMMARS`

Residual existence survives but one or more reliable strata show prospectively strong divergence/transfer failure.

#### `NO DETECTABLE RESIDUAL GRAPH BEYOND LOWER-ORDER OCCUPANCY ARCHITECTURE`

The graph-level residual-existence gate fails against independent test nulls.

#### `RESIDUAL TOKEN-CONSTRUCTION RESULT INCONCLUSIVE`

Support/reliability prevents any of the above classifications.

Exact numerical gates must be frozen before target reveal.

## What each outcome changes

### Shared residual graph

This would be materially stronger than #58A/#58B raw graph evidence. It would justify treating a common token-internal construction mechanism as a manuscript-wide surface constraint and testing whether it survives representation/transcription changes.

After that, use the stable residual constraints prospectively to restrict reversible generative/inverse transform families.

### Residual graph with modulation / multiple grammars

Do not force one generator across the manuscript. Build a hierarchical model with a shared baseline plus strata-specific interactions, or distinct generators if the data require it.

### No residual graph

Downgrade the raw 66-edge occupancy graph as a candidate “deep grammar.” Much of it would then be attributable to lower-order occupancy architecture under the current representation.

Stop mining the same graph and move to a different independently motivated structural object or inverse constraint.

### Inconclusive

Record the power/representation limitation. Do not change the null, edge subset, strata or thresholds after reveal to obtain a directional result.

## Why this is a decipherment-relevant step

This test still will not tell us what the tokens **mean**.

Its value is architectural: it determines whether later decoding work can reasonably assume one shared token-construction layer across the manuscript.

That is a prerequisite for deciding whether a single reversible surface transform is a plausible manuscript-wide target or whether the inverse problem must be stratified.

## Prohibited shortcuts

Do not:

- call visible delimiters proven word boundaries;
- drift into sentence-level syntax without a new explicit program;
- choose only #58A/#58B high-scoring edges;
- use the same null ensemble to both estimate and validate residual normalization when an independent split is feasible;
- interpret cross-stratum residual similarity before residual existence survives;
- tune residual normalization after observing the real target classification;
- assign semantic meanings to slots from residual sign/strength;
- infer a cipher table or plaintext alphabet;
- revive Sloane/music from the historical origin of slot3×slot5;
- call any structural result decipherment.
