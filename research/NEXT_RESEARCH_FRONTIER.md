# Next research frontier — independent-transcription replication of the residual token-construction graph

Status: next plan-first frontier after Issue #58C first reveal and integration.

## Program-level purpose

Read `research/TOKEN_CONSTRUCTION_PROGRAM.md` first.

The object is **one space-delimited Voynich token**, not sentence-level grammar. Visible spaces are observed delimiters, not assumed natural-language word boundaries.

#58C has now answered the prior question under the frozen ZL3b/12-slot representation:

> a strong non-trivial token-internal residual interaction graph exists beyond line-local slot prevalence, with a shared core across tested manuscript strata and measurable modulation.

The next question is whether that result belongs to the manuscript rather than to one transcription/representation.

## Why the frontier moves here

Issue #58B showed that raw 66-edge graph similarity could be generated by lower-order line-local occupancy structure.

Issue #58C corrected for that problem prospectively using separate reference-null and independent test-null ensembles.

Frozen #58C result:

> **`RESIDUAL GRAPH EXISTS WITH STRATUM MODULATION`**

Key evidence:

- pooled residual energy `3.23155` vs test-null maximum `1.28318`;
- `p_exist_ALL = 1/1001`;
- physical-leaf residual reliability `W_ALL = 0.94471`;
- all seven planned strata pass residual-existence maxT at `1/1001`;
- all seven planned residual similarities beat the full independent test-null maxT ensemble;
- no contrast qualifies as materially different/multiple grammar.

Therefore repeating the ZL3b residual test has low information gain. The main live alternative is now transcription/parser dependence.

## Primary new question

> **Does a materially independent Voynich transcription/reading reproduce a non-trivial residual token-construction graph without retuning the slot grammar or selecting favorable edges?**

If yes, a second question follows:

> **Does its complete 66-edge residual topology agree with the already frozen ZL3b #58C graph strongly enough to support a manuscript-level shared construction constraint?**

A third, coarser question is:

> **Does the shared-core-plus-modulation geometry replicate even if individual edge magnitudes differ?**

## Source audit must precede target planning

Before any independent-transcription residual score is computed, audit candidate sources.

Required audit outputs:

1. exact source authority/provenance and immutable identifier/hash where possible;
2. whether the reading is materially independent of ZL3b rather than a formatting derivative;
3. physical-leaf overlap with the #58C analyzed population;
4. preservation/meaning of visible token and line boundaries;
5. glyph/alphabet conventions relevant to the frozen 12-slot parser;
6. whether the existing parser accepts the independent reading directly;
7. if normalization is unavoidable, an outcome-independent normalization rule defined before target scores;
8. parsed-token coverage overall and by physical-leaf fold;
9. support for the already used Currier/section/line-position strata where metadata can be aligned independently;
10. any source-specific ambiguity that would make exact 66-edge replication scientifically unfair.

Do not force a source through the 12-slot representation if compatibility requires outcome-dependent remapping.

## Required replication design before target reveal

### 1. Retain the complete graph

Use all 66 unordered slot pairs. Do not select saturated, high-magnitude, stable, or visually attractive #58C edges.

### 2. Independent residual-existence test

The independent transcription must get its **own** prospectively frozen line-local null calibration. Reusing ZL3b edge-wise null distributions as if they were universal would confound transcription conventions with residual interaction.

Use separate reference-null and validation-null ensembles or a stronger predeclared non-circular equivalent.

The independent residual graph must first pass a graph-level existence/reliability gate before cross-reading topology is interpreted.

### 3. Cross-reading graph replication

If independent residual existence passes, compare its full 66-edge residual vector against the frozen ZL3b vector.

Freeze before reveal:

- exact similarity statistic(s);
- treatment of finite-reference saturation/ties;
- null or randomization used to judge cross-reading agreement;
- physical-leaf held-out replication/transfer if feasible;
- numerical gates for replicated / related-but-representation-modulated / failed topology replication.

### 4. Geometry replication

Separately assess whether the broad #58C conclusion replicates:

- strong residual existence overall;
- residual existence across supported manuscript strata;
- stronger within-Currier-B section agreement than exact-uniformity claims;
- modulation involving Currier A/B and/or line-initial context, if those strata are independently supportable.

This geometry test must be predeclared coarser structure, not a post-hoc list of whichever #58C details happen to survive.

### 5. No retuning against ZL3b outcome

Do not change after independent target reveal:

- glyph normalization;
- slot assignment/grammar;
- edge subset;
- source overlap population;
- similarity metric;
- replication threshold;
- strata included in confirmatory geometry.

Any material redesign is a new phase.

## Decision branches

### `INDEPENDENT TRANSCRIPTION REPLICATES RESIDUAL TOKEN-CONSTRUCTION CORE`

Independent residual existence passes and complete-graph/geometry replication satisfies frozen criteria.

Consequence:

- promote the replicated residual constraints to manuscript-level surface-generation constraints;
- use only replicated/stable constraints prospectively in reversible/generative/inverse model testing.

### `RESIDUAL CONSTRUCTION REPLICATES, TOPOLOGY IS REPRESENTATION-MODULATED`

Independent residual existence is strong, but exact complete-graph topology shifts while a predeclared coarser structural core survives.

Consequence:

- retain non-trivial token construction as manuscript-real;
- identify the coarser representation-invariant constraint before inverse-model use;
- do not hard-code ZL3b-specific edge magnitudes.

### `ZL3B RESIDUAL GRAPH DOES NOT REPLICATE INDEPENDENTLY`

Independent residual existence or frozen topology-replication requirements fail under adequate support.

Consequence:

- downgrade #58C from manuscript-level candidate to ZL3b/parser-dependent result;
- do not use its exact graph as a decipherment constraint.

### `INDEPENDENT-TRANSCRIPTION REPLICATION INCONCLUSIVE`

Source compatibility/support or frozen statistical power is inadequate.

Consequence:

- record the limitation;
- do not tune transcription normalization or select easier strata/edges after reveal.

## Why this is decipherment-relevant

#58C provides a strong enough token-internal constraint that the next useful step is no longer another local occupancy discovery.

A successful independent-reading replication would let later models be rejected for failing a **manuscript-level token-construction signature**, not merely a transcription-specific statistic.

That materially narrows the inverse problem:

- if the core is portable, one shared surface-generation layer with modulation becomes a serious design constraint;
- if only coarser structure is portable, inverse models must target that coarser invariant;
- if it does not replicate, the exact #58C graph should not steer decipherment.

## What comes after successful replication

If independent-transcription replication succeeds, the next major frontier is a **prospectively constrained reversible/inverse model family** that must jointly reproduce:

- the replicated token-construction residual constraints;
- accepted A1/H62 local recurrence geometry;
- the difficult S1 paragraph-entry specialization;
- other accepted manuscript-level structural constraints without post-hoc tuning.

That is the point where this token-construction lane begins directly constraining candidate decoding/generation algorithms rather than merely characterizing surface text.

## Prohibited shortcuts

Do not:

- call visible delimiters proven words;
- drift into sentence syntax without a new explicit program;
- choose only #58C high-scoring edges;
- tune independent glyph mapping to maximize ZL3b graph correlation;
- use ZL3b's residual null distribution as the independent source's calibration without justification;
- interpret cross-reading topology if independent residual existence fails;
- require exact invariance merely because #58C showed a shared core — #58C itself supported modulation;
- assign semantic meanings to slots;
- infer a plaintext alphabet or cipher table;
- call replication decipherment.
