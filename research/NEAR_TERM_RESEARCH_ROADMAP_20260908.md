## Why this order is now fixed

The program has already answered enough local-statistic questions that continuing to add nearby surface features would have low information value.

Accepted results that drive this roadmap:

- certain visible spaces replicate as production/construction boundaries across ZL3b and IT2a;
- bounded-unit internal topology is largely reproduced by a compact second-order occupied-slot grammar;
- memoryless V2 code length is about 9.7 bits/token, with about 7.0 bits in shape and about 2.7 bits in values;
- cross-unit predictive information is real but small relative to token-internal information;
- useful local recurrence/cache exists, but Phase69–70 showed that strong local recurrence can coexist with **exactly recoverable meaningful plaintext**;
- observable local/slow mechanisms largely close the predictive residual; Issue #134 does not license a new rich latent-state search;
- the same-line previous-terminal → next-initial edge is robust across ZL3b/IT2a and resets at source-line breaks under the frozen Voynich tests;
- Issue #181 showed that a real solved Borg monoalphabetic ciphertext can exhibit the same qualitative line-local edge topology, so R5 is now a **compatibility responsibility**, not a standalone anti-cipher discriminator;
- Issue #182 could not cleanly attribute the Borg topology to plaintext lexical structure versus physical wrapping because the benchmark plaintext transport destroyed some line-split information; nevertheless 260 cross-line events were independently reclassified as within-word splits on the compatible population;
- Currier A/B adds real next-initial information, but the accepted difference largely factorizes to a context-invariant outcome bias rather than a second context-specific grammar;
- slower history is dominated by causal-prefix / prior-paragraph inventory, not detailed long ordered memory;
- repeated local image↔label/body morphology searches were null despite a successful external botanical positive control; that object-local representation-search population is exhausted;
- A1 and Naibbe remain complementary partial models rather than joint explanations;
- Phase71's frozen Alberti paragraph-boundary mechanism did not reproduce the Voynich paragraph-entry direction;
- Issue #180 did not promote the line-managed allographic LM-A0 family after its external preflight;
- Issue #183 confirmed a real 1463 mixed-granularity cipher family but could not recover a sufficiently specified encoder/inverse; inventing segmentation/homophone/null policies is not licensed.

The scientific question is therefore no longer “what other local statistic does Voynich have?” It is:

> **What independently documented production/encoding mechanisms can generate the particular combination of productive bounded-unit construction, signed paragraph-entry specialization, thin cross-unit information, line-local edge behavior, slow inventory memory and exact recoverability where claimed?**

# Priority 1 — R4 / S1 external mechanism attribution

## Why first

R4 is currently a sharper discriminator than R5.

- A1 reproduces the signed paragraph-entry responsibility.
- Naibbe does not.
- Exactly reversible meaningful-plaintext Phase69/70 constructions reproduce strong recurrence and much aggregate line-position structure but leave S1 far below the Voynich regime.
- The frozen Alberti paragraph reset produced the wrong S1 direction.
- Borg has weakened R5 as an anti-cipher discriminator, but no analogous external result has yet weakened R4 to the same degree.

Therefore the next high-value question is:

> **Which independently known document-production mechanisms naturally produce a Voynich-like signed paragraph-entry specialization?**

## Required design

Before any new external score:

1. freeze the exact historical S1 replay statistic and sign convention;
2. choose externally motivated corpora by production mechanism, not by preliminary S1 behavior;
3. preserve true paragraph/item/message boundaries from source authority;
4. include several architecture classes where feasible, such as ordinary prose, recipe/formula/list records, structured administrative/tabular records, real historical ciphertext with preserved message/paragraph boundaries, and highly formulaic manuscript text;
5. use held-out/document-level or manuscript-level replication rather than pooled significance only;
6. report null and wrong-sign results without mechanism-specific rescue.

## Decision use

The purpose is not to prove semantics. It is to narrow mechanism classes prospectively.

- If one mechanism class repeatedly gives the correct signed entry topology, promote that class to candidate-selection consideration.
- If the effect is common across unrelated external classes, downgrade R4's discrimination weight while retaining it as a compatibility responsibility.
- If the effect remains rare and wrong-sign in controls, R4 becomes the leading external falsifier for the next #172 candidate.

# Priority 2 — productive/open-vocabulary responsibility audit

## Motivation

Our compact token grammar and held-out code-length work already suggest that the manuscript is not well described as a simple memorized vocabulary. A recent independent line of work also emphasizes a hapax-rich/open vocabulary. This should be converted from an informal observation into a prospective responsibility before it is used to eliminate codebook families.

## Question

> **Does the Voynich surface system continue to generate genuinely novel legal forms on held-out leaves at a rate/structure that cannot be reduced to finite vocabulary lookup plus sampling noise?**

## Required measures

Freeze before reveal, at minimum:

- held-out new-type rate;
- type accumulation / vocabulary-growth curve;
- decomposition of novel types into:
  - known shape + new value combination;
  - new occupied-slot shape;
  - edit-near family innovation;
  - other parser-accepted innovation;
- physical-leaf cross-validation;
- ZL3b/IT2a replication under a common representation where definitionally possible;
- finite-vocabulary and productive-grammar controls with matched token counts/frequency skew.

## Program role

If robust, this may become a separately preregistered **R11 productivity/open-vocabulary responsibility**. It must not be inserted retroactively into already-revealed #172 scorecards.

A robust positive would be especially useful against:

- closed nomenclators/codebooks;
- empirical target-vocabulary lookup models;
- finite-list generators that match token frequencies but do not generate new legal forms.

It would not distinguish meaningful encoding from non-semantic procedural generation by itself.

# Priority 3 — clean R5 source attribution

## Current state

Issue #181 established that a real historical Borg monoalphabetic ciphertext can show a line-local edge with harmful cross-line carry. Issue #182 showed that the available benchmark transport is unsuitable for clean full-corpus attribution because physical line wraps can split one lexical word while the committed plaintext representation destroys that distinction.

Therefore do **not** continue repairing Borg by increasingly permissive transport rules.

## Next question

Find an independent historical corpus for which the following are all preserved from source authority:

1. ciphertext symbols;
2. cipher-unit/group boundaries;
3. physical lineation;
4. solved plaintext with lexical boundaries;
5. key/alignment or a deterministic scholarly mapping between ciphertext and plaintext.

Then freeze a stagewise attribution test:

`plaintext transition -> encryption/relabeling -> cipher grouping -> physical lineation`

The goal is to determine where the line-local edge appears or disappears.

## Decision use

- plaintext already has the topology -> R5 may largely be inherited source structure;
- encryption/grouping introduces it -> prioritize mechanisms with documented grouping choice;
- physical lineation introduces/reset it -> layout/source-line production becomes independently motivated again;
- no clean attribution possible -> retain R5 only as compatibility and stop spending the main lane on it.

No result from this external lane directly repairs A1, Naibbe, Alberti, LM-A0 or T1463.

# Priority 4 — select one historical multi-glyph reversible mechanism

Only after Priorities 1–3 should a new historical candidate be admitted.

## Minimum admission criteria

A candidate should have, from external authority before Voynich scoring:

1. **documented multi-glyph ciphertext/output construction**, not merely opaque one-sign substitution for a digram or word;
2. a documented or reconstructible encoder choice policy;
3. enough detail to define segmentation/grouping without Voynich-derived repair;
4. enough detail to define an inverse and the exact level of recoverability;
5. no target vocabulary lookup;
6. no post-hoc Currier, paragraph-cache, line-reset, illustration or recurrence module added because the #172 battery contains those responsibilities;
7. explicit R10 accounting for dictionaries, key material, layout access, side information and state.

## Selection rule

Prefer one well-specified mechanism over a large tournament of vaguely reconstructed families.

T1463 remains useful historical evidence for mixed-granularity practice, but `H0_ARCHITECTURE_PARTIAL` means it is not currently an executable candidate.

# Parallel content lane — page/paragraph inventory, not object-local token matching

The prior pharmaceutical object-local program has exhausted the tested morphology→label/body representations. Do not reopen that population by changing tokenization, embeddings, visual descriptors or similarity metrics.

A distinct content question remains reasonable because:

- previous-paragraph / causal-prefix inventory carries slow predictive information;
- external literature has reported page-level topic/illustration/scribe associations;
- local nulls do not imply semantic absence.

## Gate before science

Before association scoring, audit whether subject/illustration class is sufficiently crossed with Currier, section and hand/scribe to identify an effect.

If not, classify `NOT IDENTIFIABLE` and stop.

If identifiable, freeze a held-out test of whether residualized page/paragraph **inventory composition** predicts an externally defined subject class after controlling known production variables.

This lane is independent of the mechanism lane and cannot be used to tune a cipher/generator candidate.

# Operating rule for new work

For every proposed experiment, first ask:

1. Does an accepted result already answer the broad question?
2. Does this experiment discriminate mechanism classes, or merely describe another correlated statistic?
3. Is the hypothesis independently motivated before Voynich target scoring?
4. Can a clean null/wrong-sign result terminate the lane?
5. Is the work advancing one of the five priorities or the single parallel content lane above?

If the answer to 5 is no, the default decision is **defer** until this roadmap is explicitly revised.

This roadmap is intentionally restrictive. The program has enough surface discoveries; the near-term objective is now causal/mechanistic discrimination with minimal target-driven search.
