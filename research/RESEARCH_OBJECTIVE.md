# Research objective — discovery first, falsification as method

This file defines the purpose of the LETSGO-Voynich research program. It is normative for **research direction and priority**. Phase-specific frozen plans/results/reports remain authoritative for exact methods and historical numerical results; `RESEARCH_PROTOCOL.md` remains authoritative for evidential discipline.

## Core objective

The objective is not to accumulate falsified hypotheses or to eliminate every imperfect model.

The objective is to discover a constrained mathematical account of the Voynich text that progressively approaches an explanatory and, where possible, decipherable transformation.

The main search loop is:

1. identify reproducible structure in the manuscript;
2. find mathematical transformations or generative mechanisms that reproduce part of that structure;
3. determine which parts of those mechanisms are robust, transferable, and independently constrained;
4. test whether the useful structure can coexist with meaningful information, especially under reversible mappings;
5. when a sufficiently constrained reversible transformation family exists, formulate the inverse problem and test whether applying it to unseen Voynich material recovers stable, predictive, interpretable information;
6. use falsification, held-out tests, controls, and external evidence to prevent flexible mappings from masquerading as decipherment.

Thus **falsifiability is a search discipline, not the research objective**.

## What a failure means

A failed joint gate rejects only the claim actually tested.

In particular:

- failure as a complete manuscript model does not automatically invalidate a mechanism that robustly explains one component;
- failure of one coordinate does not erase successful prospective predictions on another coordinate;
- a mechanism that is not historically identified can still be valuable as a mathematical transform or scaffold for discovering the actual transform;
- when another mechanism reproduces the same statistic, the statistic becomes less discriminative, but the original mechanism does not thereby become useless;
- negative results should prune unsupported claims, not erase reusable structure.

The project should distinguish **falsified as sufficient**, **falsified in a specific role**, **retained partial mechanism**, and **open transform family** rather than collapsing these into a single notion of rejection.

## Constructive versus eliminative tests

A next experiment should be chosen by expected information gain toward the core objective, not by a default preference for the next possible falsification.

A falsification/discrimination test is appropriate when it materially narrows the admissible transformation family or prevents a flexible explanation from surviving without cost.

A constructive/inverse test is appropriate when prior work has already produced a constrained mechanism with reusable explanatory power, especially if that mechanism can be embedded in an exactly reversible meaningful-text construction.

The two modes are complementary. Neither has permanent priority.

## A1-specific correction

A1 is not valuable because it is presumed to be the historical production algorithm. Its central value is that it provides a mathematically explicit way to reproduce several Voynich-like structural effects and therefore exposes candidate transformation principles that can be reused, transferred, constrained, or inverted.

The Phase69–70 meaningful-text experiments strengthen this interpretation. They show that important A1-like recurrence structure can coexist with exactly recoverable meaningful plaintext under a reversible surface layer. That result should not be read primarily as a reason to eliminate A1 because the same statistic is non-unique. It should also be read constructively: a useful part of the A1 transform has crossed from a stand-alone generator into a meaning-preserving reversible transformation family.

Accordingly, the existence of an unresolved component such as paragraph-entry specialization means that A1 is not a sufficient complete model. It does **not** imply that the already successful A1-derived transformation machinery should be discarded before testing its value in the inverse problem.

## Current course correction

Earlier repository language increasingly framed the project as `constraint discovery` or `mechanism-family discrimination`. Those are legitimate methods, but they are subordinate to the objective above.

The practical correction is:

> Do not ask only, “what can we falsify next?” Ask, “which next experiment most efficiently moves from observed Voynich structure toward a constrained transform that can make new predictions or be inverted?”

For the current state, this means that inverse/decoding-oriented work on constrained reversible surface transformations is a first-class frontier alongside external discriminators. An external discriminator should not automatically outrank an inverse test merely because it offers another opportunity to reject a model.

## Guardrails retained

This correction does not relax the project’s evidential standards.

Retain:

- preregistration or frozen rules before decisive reveals;
- held-out and prospective testing;
- explicit complexity/degrees-of-freedom accounting;
- strong null and matched-control design;
- independent transcription/external replication where relevant;
- exact recording of negative results;
- no post-result repair disguised as confirmation;
- no decipherment claim without stable unseen prediction and interpretable output.

The correction changes **what the methodology serves**, not the rigor of the methodology itself.
