## 1. Independence unit

The five process paths `rep0..rep4` are **five stochastic executions of Naibbe over the same four Latin source manuscripts**. They are not five independent textual datasets.

Therefore Stage C must not create 20 pseudo-independent folds from `5 reps × 4 manuscripts`.

For any fold-based reliability quantity:

- use exactly **4 manuscript folds**;
- fold 0 = all five BIS193 process paths;
- fold 1 = all five CLM13027 process paths;
- fold 2 = all five Mazarine915 process paths;
- fold 3 = all five UBL758 process paths.

The five paths improve integration over algorithmic stochasticity; they do not multiply independent source evidence.

## 2. Primary estimand

For each axis `a ∈ {EL,ES,ET,EG}`, assignment `j=0..30`, and target reading `t ∈ {ZL3b,IT2a}`:

1. use the **exact C0 common-support positions** for `(a,j)`;
2. build the baseline occupancy matrix on those positions;
3. build the randomized occupancy matrix on those same positions;
4. calculate candidate-owned line-local reference-null residual-Z coordinates separately for baseline and randomized surfaces using the same scientific statistic and deterministic namespace policy;
5. compare each complete 66-edge residual vector with frozen target `t`;
6. define

`DELTA_R[a,j,t] = R_randomized[a,j,t] - R_baseline_common_support[a,j,t]`.

Interpretation:

- `DELTA_R < 0`: the published assignment is more Voynich-R1-like on the exact paired support;
- `DELTA_R = 0`: no observed topology loss;
- `DELTA_R > 0`: the randomized assignment is at least as or more Voynich-R1-like.

This paired support contrast is the **primary causal estimand**. Full-support coverage/E/W/topology values are secondary/descriptive because intervention-dependent parser acceptance can otherwise confound the comparison.

## 3. Target reading symmetry

ZL3b and IT2a are two independent Voynich transcription/readings of the replicated R1 target.

Do not average them into one scalar primary score.

For every assignment report both `DELTA_R_ZL3b` and `DELTA_R_IT2a`.

Axis-level interpretation must state whether direction agrees across both readings.

A result driven by only one reading is weaker and must be labeled reading-sensitive rather than rescued by averaging.

## 4. Randomization rank quantity

For each axis and reading, after all 31 assignments are scored, calculate:

`rank_nonloss = (1 + count_j[DELTA_R_j >= 0]) / 32`.

Also report the exact numerator count.

This quantity is an **outcome-independent sampled-assignment rank / Monte Carlo non-loss frequency** under the preregistered assignment generator.

It is **not** to be described as:

- an exact permutation p-value;
- proof that the published mapping was randomly sampled from the null family;
- a classical significance test with a scientifically privileged `.05` cutoff.

The assignment space is sampled by 31 deterministic hash-generated reassignments rather than exhaustively enumerated, and the historical published map was not itself generated by that randomization law.

Therefore Stage C will report the rank evidence continuously.

No axis receives a categorical causal PASS/FAIL solely because this quantity falls above or below `.05`, `.10`, `1/32`, or another conventional threshold.

## 6. Residual reference-null calibration

The line-local reference null remains the same construct as #58C/#58D/#68: it asks whether complete token-internal slot-pair topology exceeds line-local occupancy expectations.

For Stage C paired contrasts:

- every baseline/common-support and randomized/common-support surface receives a candidate-owned deterministic 1,000-reference-null calibration;
- null shuffling operates only within the exact selected common-support line fragments used by that surface comparison;
- baseline and randomized surfaces for one `(axis,j)` use distinct, preregistered namespace labels to prevent accidental RNG identity from being mistaken for paired data identity;
- no test-null p-value is required for the primary `DELTA_R` causal contrast because C1 is not re-testing whether each surface independently has an R1 residual graph; the target comparison is the estimand.

The accepted #58C/#58D target vectors remain frozen and are never refit.

## 8. Representation loss is a separate outcome

C0 already showed large axis-specific representation effects:

- EL median parser coverage ≈ `.8324`;
- ES ≈ `.5843`;
- ET ≈ `.8690`;
- EG ≈ `.5451`;
- baseline pooled five-path coverage ≈ `.8865`.

Those effects are scientifically meaningful but cannot substitute for paired R1 causality.

Stage C interpretation must separate:

1. **representation effect** — the assignment changes how often tokens are expressible in the frozen 12-slot representation;
2. **paired R1 topology effect** — among positions jointly observable under baseline and intervention, the assignment changes similarity to the replicated Voynich residual topology.

Especially for ES and EG, any strong R1 change must be reported alongside the fact that common support is often only about one-half to three-fifths of visible positions. The claim must narrow if low support materially limits generalization.

No coverage cutoff will be retrofitted.

## 9. Process-path aggregation

Primary Stage C scores pool all five process paths while preserving line identity and manuscript identity, because the estimand is the expected fixed-assignment effect integrated over the five already-frozen stochastic paths.

However, to diagnose whether one favorable path dominates, also report per-process-rep `DELTA_R` using the same C0 support for that rep where computationally feasible.

These five values are repeated algorithmic realizations and are descriptive replication of direction, not five independent inferential observations.

Axis-level claim strength should be reduced if the pooled direction is carried by one path and reverses in most others.

## 11. Permitted causal language after C1

If an axis shows a consistently negative `DELTA_R` distribution in both readings and across process-path diagnostics, Stage C may say:

> **Within the tested published Naibbe configuration and frozen source panel, preserving this nominated assignment structure contributes to the mechanism's Voynich-like R1 topology conditional on the realized encryption paths.**

It may not say:

- the same layer is historically Voynich;
- that layer alone explains R1;
- Latin is decoded;
- the assignment is necessary across all possible Naibbe paths;
- the axis is a unique historical mechanism.

If randomized assignments frequently match or improve on the published assignment, the licensed conclusion is narrower:

> **The nominated published association is not specifically required for Naibbe's R1 proximity under this fixed-path randomization family.**

That does not imply the whole layer is irrelevant; the chosen invariance class may preserve other structure in the layer.
