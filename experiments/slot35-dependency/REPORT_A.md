## What the 5×5 table actually looks like

Rows are slot3 `EMPTY,t,k,p,f`; columns are slot5 `EMPTY,cth,ckh,cph,cfh`:

```text
              slot5
             Ø    cth  ckh  cph  cfh
slot3 Ø   12888   622  561  123   32
      t    3540     1    0    0    1
      k    6475     0    0    0    0
      p     672     0    0    0    1
      f     155     0    0    0    0
```

Pooled descriptive association:

- empirical mutual information: **`0.04475475 bits/token`**;
- Cramér's V: **`.10331456`**.

The structure is overwhelmingly an occupancy exclusion:

- when slot3 is EMPTY, slot5 is nonEMPTY in **1,338 / 14,226 = 9.405%** of parsed tokens;
- when slot3 is nonEMPTY, slot5 is nonEMPTY in only **3 / 10,845 = 0.0277%**;
- the nonEMPTY-slot5 rate is therefore about **340× higher** when slot3 is EMPTY.

Only three parsed tokens in the complete population have both slots nonEMPTY.

## Interpretation

The E10 4/5 recurrence was not merely a meaningless artifact of the Sloane plaintext table. There is a real, reproducible manuscript-side relation between the two native factors: knowing one slot improves prediction of the other on unseen physical leaves, and the effect survives line-local frequency-preserving pair destruction.

However, the 5×5 table immediately changes the next question. The signal is not obviously a rich 25-cell association. It is dominated by near-mutual-exclusion of **occupancy**: slot3 and slot5 are almost never simultaneously nonEMPTY.

That distinction matters because a binary occupancy rule could arise from token morphotactics or from how the slot decomposition separates alternative graphical constructions. If binary occupancy explains essentially the entire information gain, the E10 recurrence should not be described as evidence for a higher-dimensional 5×5 code.

## Required next test

Do not interpret the result semantically yet.

The next plan-first audit should decompose the association into:

1. binary `EMPTY/nonEMPTY` occupancy dependence;
2. any residual subtype-level dependence after that occupancy interaction is modeled;
3. parser/slot-construction admissibility, including whether all canonical slot3×slot5 state combinations are syntactically parseable in principle.

If the full 5×5 signal reduces almost entirely to binary occupancy exclusion, retain it as a morphotactic constraint rather than a 25-state structural code.
