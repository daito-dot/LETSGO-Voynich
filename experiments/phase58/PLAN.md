# Phase 58 plan — prospective tests of the robust residual

Status: pre-execution plan. Frozen before looking for content/cipher associations.

## Input frozen from Phase57

Only the leading approximately 2-dimensional consensus paragraph residual is eligible. Higher residual axes are not stable enough across window scale/representation and may not be used for post-hoc semantic rescue.

## Core question

Does the structurally residual paragraph state predict independently grounded manuscript content better than matched structural controls?

A positive result would establish an information-bearing relation, not a decipherment.

## Test order

### 58A — internal document-role transfer control
Before visual semantics, verify that the residual does not simply reconstruct labels already used or closely correlated nuisance labels. Predict held-out metadata not included in the residualizer where available (quire, recto/verso, physical-order bins) under matched section/hand/Currier controls. Strong success here is a warning, not semantic evidence.

### 58B — independently grounded visual/content relation
Use only content labels that can be defined without reading Voynichese. Candidate domains must have reproducible annotation rules and enough matched samples. Prefer relations within the same page/section/state where possible.

Primary design:
- freeze visual/content labels before residual comparison;
- same-section / same-hand / same-Currier or same-page matched comparisons;
- predict content relation from the 2D residual;
- compare with structure-only baselines and label permutation within matched strata.

### 58C — label/text-role relation
Where labels are spatially linked to illustrations/items, test whether nearby prose residual state predicts independently defined item class or visual relation. Do not infer plaintext values from token shapes.

### 58D — bounded cipher-information test
Only after 58B/C. A cipher hypothesis must specify a bounded mapping family before evaluation. Compare held-out predictive gain against equal-complexity formal/null mappings. Deliberate deception is not an explanation unless its nuisance mechanism is explicitly parameterized and complexity-charged.

## Frozen hypotheses

### H58-1 — residual carries independent content information
The 2D robust residual predicts independently annotated content above matched permutation/null controls.

### H58-2 — residual is only unmodeled document structure
Residual predicts physical/document nuisance labels but not independent content after matching.

### H58-3 — no detectable information at this representation
Neither nuisance nor content relations transfer. This weakens the current residual representation as a decipherment target but does not prove absence of meaning.

## Promotion rule

No result may be described as decipherment unless an executable mapping predicts substantial unseen material with fixed interpretable output. Phase58 can at most establish that a robust structural residual does or does not carry independently grounded information.
