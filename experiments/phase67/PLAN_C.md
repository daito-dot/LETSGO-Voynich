# Phase 67C — image morphology -> A1-formal-residual body text

Status: **FROZEN BEFORE FORMAL-RESIDUAL MORPHOLOGY↔TEXT ASSOCIATION**

Date: 2026-08-31

## Motivation and sequential status

Phase67A and Phase67B both rejected direct coupling between pharmaceutical image morphology and the surface character-ngram distribution of the immediately following paragraph.

Those nulls do not yet test a representation that explicitly removes the strongest formal mechanisms already established elsewhere in the repository. Phase61–64 identify two important non-content processes:

1. a paragraph-entry register concentrated on line 0;
2. a short-range local family process in which a body token may be a non-identical edit-distance-1 neighbor of one of the previous ten tokens on the same physical leaf.

Phase67C therefore asks a new question:

> After conservatively masking tokens that are directly compatible with those two established formal mechanisms, does the remaining body-token surface structure carry a detectable relation to the sealed image morphology?

This is an adaptive follow-up chosen after Phase67A/B were observed. Therefore any positive result is **candidate evidence only** and requires a separately frozen independent replication on earlier pharmaceutical folios before promotion.

A null result is allowed to close this particular formal-residual surface detector. It does not rule out syntax, cryptographic transformations, nonlocal recipe relations, or semantics not represented by the image characters.

## Formal-mask rule

The mask is fixed from the already published A1 architecture. It is not trained on Phase67 morphology.

Process the frozen body paragraphs in manuscript order within each physical folio. Maintain a FIFO history of the previous ten **complete conservatively cleaned tokens** on that folio. History persists across line and paragraph boundaries.

For every cleaned token:

1. If the token is on paragraph line 0, classify it `ENTRY_MASKED`.
2. Otherwise, before appending the current token to history, if it is Levenshtein distance exactly 1 from any of the previous ten tokens, classify it `LOCAL_EDIT1_MASKED`.
3. Otherwise classify it `INNOVATION_RETAINED`.
4. Append every cleaned token, including masked tokens, to the ten-token history.

`lev1` is exactly the Phase61C implementation relation:

- exact equality is **not** edit1;
- one substitution, insertion, or deletion is edit1;
- length difference >1 is not edit1.

Important consequence: this is a conservative compatibility mask, not a claim that each masked observed token was actually generated by A1. It deliberately removes all observed tokens that could directly instantiate the two strongest A1 formal channels.

## Text cleaning

Use the same conservative cleaning as Phase67A/B before the formal mask:

1. `.`, `,`, whitespace, and `<->` are separators;
2. paragraph markers are removed;
3. retain only lowercase complete alphabetic tokens matching `^[a-z]+$`;
4. discard tokens containing editorial/transcription uncertainty markup rather than resolving them.

The formal history uses only tokens that survive this cleaning.

## Primary residual text vector

For each of the 14 paragraphs, use only `INNOVATION_RETAINED` tokens.

Count within-token character n-grams for n=1,2,3.

For each n independently:

- vocabulary = grams present in at least two of the 14 retained-token paragraphs;
- counts -> relative frequencies within that n;
- Hellinger transform `sqrt(p)`;
- concatenate n=1,2,3 after scaling each n-order block by `1/sqrt(3)`.

If a paragraph has zero retained grams for an n-order, its vector for that order is zero. A paragraph is not removed merely for having few retained tokens.

## Image predictor family

Use exactly four previously sealed image characters:

1. `leaf_composition`
2. `leaf_arrangement`
3. `leaf_margin`
4. `root_subterranean_architecture`

For each character separately, use the same block representation already frozen in A/B:

- exclude object-level `U` states;
- proportions over non-U states;
- Hellinger transform;
- a block with no non-U observations is unusable for that character.

No new image feature is introduced.

## Folio-state control

For each character independently:

- retain its usable blocks;
- only folios with at least two usable blocks contribute;
- within each contributing folio, subtract the folio mean from both image and residual-text vectors.

## Primary statistic

For each of the four image characters compute the normalized RV coefficient between centered image state matrix `X_c` and centered residual-text matrix `Y_c`.

Primary family statistic:

`T = max(RV_leaf_composition, RV_leaf_arrangement, RV_leaf_margin, RV_root_architecture)`.

This four-way maximum is frozen before the Phase67C score is opened.

## Exact null

Hold all masked/retained paragraph representations and image annotations fixed. Permute complete residual paragraph vectors among blocks **within folio only**.

The exact assignment space is unchanged:

`4! * 3! * 2! * 1! * 2! * 2! = 1,152`.

Enumerate all 1,152 assignments, identity included. Recompute all four RVs and the four-way maximum for every assignment.

Exact one-sided family p-value:

`p = count(T_perm >= T_obs) / 1152`.

## Operational coverage gate

A Phase67C association is retained only if:

1. global four-way exact p <= 0.05;
2. the winning image character has at least 8 centered usable blocks;
3. those blocks span at least 3 contributing folios.

Because this is a sequential/adaptive detector, a gate-passing result is classified:

`CANDIDATE FORMAL-RESIDUAL IMAGE↔BODY ASSOCIATION — INDEPENDENT REPLICATION REQUIRED`

not as supported structure.

Also report global totals.

These are descriptive diagnostics, not tunable thresholds.

## Retention / observability nuisance control

A new text-side nuisance is introduced by masking: some paragraphs may retain a larger fraction of tokens than others.

For each image character:

1. define paragraph retention fraction = retained innovation count / cleaned token count;
2. within the same usable blocks/folios as the character, center retention fraction within folio;
3. compute retention-only RV against the centered image state matrix;
4. residualize the centered residual-text matrix on centered retention fraction (no intercept, because folio means are already removed);
5. recompute image↔text RV and repeat all 1,152 permutations;
6. use a second four-character maxT for the retention-residualized analysis.

If the primary four-way p<=0.05 but the winning character's retention-only p<=0.05, require the retention-residualized four-way maxT p<=0.05 and the same coverage gate; otherwise classify `TEXT-RETENTION CONFOUNDED`.
