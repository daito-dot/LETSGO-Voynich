Its result is methodological but important:

> **The project now has an audited set of mutually compatible responsibilities that can reject mechanisms prospectively, without changing the tests after seeing candidate failures.**

That is the point at which the research moves from discovering isolated regularities to using a replicated constraint system against explicit generative/inverse models.
