## 5. Occupancy representation

For every successfully parsed token, construct the same binary vector

`B in {0,1}^12`

where `B_s=1` iff parser slot `s` is nonempty.

All unordered pairs

`E = {(i,j): 0 <= i < j <= 11}`

are retained in lexicographic order; `|E|=66`.

For edge `(i,j)`, define

`K_other = sum(B) - B_i - B_j`,

an integer in `0..10`.

The primary graph controls for `K_other`, because #58A showed that generic token occupancy complexity can materially inflate some apparent edges.

## 6. Primary signed edge parameter: K_other-conditional Mantel–Haenszel Yule Q

For one target stratum and one edge `(i,j)`, form one `2 x 2` occupancy table for every observed `K_other=k`.

For each observed `k` with unsmoothed total `n_k > 0`, add Jeffreys `alpha=0.5` to all four cells:

- `a_k = n11 + 0.5`
- `b_k = n10 + 0.5`
- `c_k = n01 + 0.5`
- `d_k = n00 + 0.5`
- `N_k = n_k + 2`

Define the smoothed Mantel–Haenszel common odds ratio

`OR_MH = [sum_k a_k d_k / N_k] / [sum_k b_k c_k / N_k]`.

Then map it to bounded signed Yule Q:

`Q = (OR_MH - 1) / (OR_MH + 1)`.

Thus each stratum yields a complete graph vector

`g = (Q_e)_{e in E} in [-1,1]^66`.

Interpretation:

- `Q > 0`: conditional co-construction;
- `Q < 0`: conditional exclusion / alternative construction;
- `Q ~= 0`: weak conditional association.

No unobserved `K_other` stratum is created merely by smoothing.

## 7. Primary graph similarity

For every planned contrast `(S,T)` compute the ordinary Pearson correlation across the complete 66-edge vectors:

`R_full(S,T) = corr(g_S, g_T)`.

If either real graph vector has zero variance, the contrast is mechanically `INCONCLUSIVE`.

Pearson is primary because the hypothesis concerns preservation of the signed relative graph topology, not equality of absolute edge magnitudes.

Non-promoting sensitivities:

- Spearman rank correlation over all 66 edges;
- cosine similarity over all 66 edges;
- raw unconditional 2x2 Jeffreys-smoothed Yule Q graph without `K_other` conditioning.

These sensitivities cannot promote a primary classification.

## 8. Five-fold physical-leaf reliability and cross-stratum transfer

For each target stratum `S` and held-out physical-leaf fold `f`:

- `g_S,-f`: primary conditional graph estimated from S tokens in the other four folds;
- `g_S,f`: graph estimated from S tokens in held-out fold `f`.

Within-stratum reliability for fold `f`:

`W_S,f = corr(g_S,-f, g_S,f)`.

Frozen summary:

`W_S = median_f W_S,f`.

For ordered transfer `S -> T`:

`X_S->T,f = corr(g_S,-f, g_T,f)`

and

`X_S->T = median_f X_S->T,f`.

Every pairwise contrast therefore has two directional transfer summaries.

This construction prevents the source graph used for transfer from seeing physical leaves assigned to the target held-out fold.

If a held-out or training graph has zero variance, that fold correlation is invalid; if fewer than 4 of 5 fold correlations are valid for a required summary, that stratum/transfer is `INCONCLUSIVE`.

## 9. Primary similarity null and multiplicity

Use exactly `1,000` deterministic null populations.

For each physical line and each of the 12 slots independently, relocate occupied states among the **parsed-token rows of that same line**, preserving:

- the exact set of physical lines;
- each line length in parsed-token rows;
- each line x slot occupied count;
- page metadata / Currier / section labels;
- physical-leaf fold;
- token-position label attached to each parsed row.

Different slots are relocated independently, destroying same-token cross-slot pairing while retaining line-local slot prevalence.

Deterministic seed namespace:

`Issue58B:GraphStability:LineSlotOccupancyShuffle:v1:<null_index>`

For every null population, compute the primary conditional graph vectors and `R_full` for all seven planned contrasts.

Define

`M_null = max(R_null,c)` over the seven contrasts.

For real contrast `c`, family-wise maxT p-value:

`p_maxT(c) = [1 + #{null: M_null >= R_real,c}] / 1001`.

Primary graph similarity is family-wise supported only if `p_maxT <= .01`.

This null tests whether the observed cross-stratum resemblance is stronger than can be generated after line-local same-token pairing is destroyed. It is not an exchangeability claim that Currier or section labels were randomly assigned historically.

## 10. Frozen contrast classification gates

For one contrast `(S,T)`, define both strata as **reliable** iff:

- `W_S >= 0.50`; and
- `W_T >= 0.50`.

### 10.1 `STABLE`

A contrast is `STABLE` iff all are true:

1. both strata reliable;
2. `R_full >= 0.70`;
3. `p_maxT <= .01`;
4. `X_S->T >= max(0.60, W_T - 0.15)`;
5. `X_T->S >= max(0.60, W_S - 0.15)`.

This requires both strong whole-graph similarity and held-out cross-stratum transfer close to the target stratum's own cross-fold reliability.

### 10.2 `RELATED_BUT_MODULATED`

If `STABLE` fails, classify `RELATED_BUT_MODULATED` iff all are true:

1. both strata reliable;
2. `R_full >= 0.40`;
3. `p_maxT <= .01`;
4. `X_S->T >= 0.30`;
5. `X_T->S >= 0.30`.

### 10.3 `DIFFERENT_OR_MIXTURE`

Classify `DIFFERENT_OR_MIXTURE` iff both strata are reliable and at least one is true:

- `R_full < 0.40`;
- `X_S->T < 0.30`;
- `X_T->S < 0.30`.

A lack of maxT significance by itself does not prove difference; if the practical difference gates are not met, the result is `INCONCLUSIVE`.

### 10.4 `INCONCLUSIVE`

Any contrast satisfying none of the above is `INCONCLUSIVE`.

The numerical thresholds are practical graph-transfer thresholds fixed before target scoring. They are not estimated from #58B outcomes.
