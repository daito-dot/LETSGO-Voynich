# Phase 66B — text-side preregistration

Status: **FROZEN BEFORE ANY PHASE66 IMAGE↔TEXT ASSOCIATION**

## Source

Primary transcription authority remains the frozen Phase65 ZL3b mapping in `experiments/phase65/SOURCE_MANIFEST_B.json` (blob `0698c0c451ad525d74b976fb241e338373166ad0`). The same 24 confidence-eligible attached labels are used; `L2.7` remains excluded.

No morphology state, color cluster, Phase65B score, or image↔text result may participate in feature selection.

## Tokenization

For the 24 frozen ZL3b labels:

- remove EVA word separators `.` from glyph counts;
- never form a bigram across a `.` boundary;
- each ASCII EVA letter is one glyph unit for this population;
- labels containing uncertainty syntax `?`, `[` or `]` are ineligible (already enforced by the Phase65 confidence firewall).

## Five frozen text feature groups

The scientific text representation has exactly five equally weighted groups.

### T1. glyph length

Number of EVA glyph units excluding word separators.

Pair distance: absolute length difference divided by the full frozen 24-label range. If range were zero, this group would be dropped before association; it is not zero in the frozen population.

### T2. first glyph

First EVA glyph unit of the label.

Pair distance: 0 if equal, 1 if different.

### T3. last glyph

Last EVA glyph unit of the label.

Pair distance: 0 if equal, 1 if different.

### T4. morphology-blind unigram-presence set

For each EVA glyph unit, compute in how many of the 24 labels it occurs at least once. Retain units with prevalence from 4 through 20 inclusive.

For two labels, distance is Jaccard distance between their retained-unigram presence sets. If both sets are empty, distance is 0.

### T5. morphology-blind bigram-presence set

Within each word separately, compute consecutive EVA bigrams. For each bigram, count in how many of the 24 labels it occurs at least once. Retain bigrams with prevalence from 3 through 12 inclusive.

For two labels, distance is Jaccard distance between their retained-bigram presence sets. If both sets are empty, distance is 0.

## Composite text distance

For each object pair:

`D_text = mean(T1_distance, T2_distance, T3_distance, T4_distance, T5_distance)`.

No learned weights, morphology-conditioned vocabulary, semantic morphemes, EVA family reinterpretation, or post-hoc feature deletion are permitted.

## Frozen feature vocabulary expected from the source-only rule

The vocabulary must be generated by executable code from the frozen source manifest and sealed before association. Any mismatch between executable output and these expected source-only values blocks the reveal.

Expected retained unigrams:

`a, c, d, e, h, k, l, o, r, s, y`

Expected retained bigrams:

`ai, al, ar, ch, dy, ee, eo, hd, ho, kc, ko, ls, ok, ol, or, os, ro, yk`

These lists were derived solely from the 24 ZL3b label strings under the frequency rules above, without consulting image measurements.

## Descriptive-only text fields

Word count / separator count is archived but excluded from the five-group scientific representation because it is effectively invariant in this P25 population (only one retained label contains an EVA dot separator). Rare first/last glyph identities are retained naturally through the categorical mismatch groups; they are not promoted as individual hypothesis tests.

## Sensitivity

IT2a may be used only as a predeclared transcription sensitivity using the same frozen five-group construction rule and the same statistical executable. It cannot replace ZL3b after seeing the primary result.

## Interpretation boundary

The text vector is structural. A detected relation would not establish plaintext, a plant name, a glyph meaning, a language, or a cipher key.
