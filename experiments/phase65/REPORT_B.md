# Phase 65B — image morphology ↔ attached-label form

Status: **CLOSED — M8-B1 NO DETECTED MORPHOLOGY RELATION**

Normative design: `PLAN_B.md`.

## Question

Within physically fixed rows of pharmaceutical plant fragments, are visually similar drawings accompanied by more similar attached Voynichese label forms?

This was deliberately narrower than semantic identification. Physical object↔label attachment was fixed independently of Voynichese similarity; image crops, sources, population, implementation, dependencies, statistics and thresholds were frozen before scientific reveal.

## Frozen population

25 physical loci were preregistered. One confidence exclusion (`f102v2 L2.7 / f102v2.16`) was frozen before crop science, leaving 24 objects:

- f102v2 primary: 11 objects, L2=6 and L3=5;
- f100v replication: 13 objects, T=4, M=5 and B=4.

All 24 text-blind crops passed the crop-quality/coverage firewall.

## Frozen primary method

- visual representation: DINOv2 ViT-S/14, frozen weights and preprocessing;
- visual distance: `1 - cosine(normalized embedding_i, normalized embedding_j)`;
- label representation: frozen ZL3b EVA, W1 primary;
- text distance: normalized unit-cost Levenshtein;
- statistic: within-row Spearman rho over unordered pair distances;
- page statistic: pair-count-weighted mean row rho;
- null: exact independent within-row label reassignment;
- pass: `T >= 0.20` AND exact one-sided `p <= 0.05`.

## Frozen classification

> **M8-B1 NO DETECTED MORPHOLOGY RELATION**

The preregistered positive local covariance between whole-crop DINOv2 drawing morphology and attached-label edit distance was not detected on the primary page and was not rescued by unchanged-code replication or any predeclared sensitivity.

The observed aggregate direction is slightly negative on f102v2 and more negative on f100v. This is not a preregistered inverse-relation test and must not be promoted as evidence for an inverse semantic rule.

## What this rejects

For this frozen population and representation, reject the working prediction that visually similar attached plant fragments should systematically carry more similar label forms.

This materially narrows the simplest direct morphology↔label-form bridge opened by Phase65A.

## What this does not reject

It does **not** establish that:

- labels lack semantic content;
- labels are not plant names;
- particular visual attributes cannot relate to particular textual attributes;
- a different independently motivated content anchor cannot work;
- Voynichese is meaningless, ciphered, plaintext, or generated by any specific mechanism.

Plant names in an ordinary language, for example, need not be orthographically similar merely because the depicted plants are visually similar.

## No-repair rule

Do not tune DINO layers, crop geometry, visual features, text distance, row definitions, transcription choice or thresholds against these outcomes and call the result a continuation of Phase65B.

Any new image↔text test must be a separately numbered, separately frozen hypothesis with a new rationale and leakage firewall.

## Next frontier

The scientifically cleaner next content test is not another whole-image similarity search. It is a new preregistered **attribute-level cross-modal test**:

1. define a bounded set of visually interpretable plant attributes without reading attached labels;
2. define a bounded textual feature family independently of the P25 image↔label outcomes, preferably from manuscript-wide label statistics or external linguistic/cipher rationale;
3. freeze directionality, multiplicity control, population and holdout rule;
4. only then reveal attribute↔text associations.

This is a new hypothesis, not a repair of M8-B1.
