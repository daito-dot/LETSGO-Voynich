## 1. Scientific question

Phase D showed that generic nonadjacent coupling determined only by slot separation improves R1 only modestly (`median T_M4-T_M3 = +0.0212177060`) and remains far below the empirical complete-signature ceiling.

The next minimal mechanism is not another set of distant edges. It is a hidden construction mode:

> **Can the replicated complete 66-edge topology be generated by a mixture of only two local K/R/S-conditioned transition grammars, with no explicit nonadjacent pair interaction at all?**

Mechanistic idea:

1. draw coarse token geometry `(K,R,S)` from the training-only empirical distribution;
2. draw one hidden token-construction mode `Z in {0,1}`;
3. within that mode, generate the complete 12-slot occupancy pattern using only position-specific unary and nearest-neighbor interaction terms.

Mixing two local grammars can induce long-range dependency because several distant slot preferences change together when `Z` changes.

## 2. Why this model is deliberately minimal

Phase E tests **two** latent modes only.

It does not simultaneously add:

- a third latent mode;
- K/R/S-dependent gating;
- explicit nonadjacent distance terms;
- named distant slot-pair interactions;
- signature-specific parameters;
- manuscript/line placement state;
- target-derived architecture changes.

This makes a negative result interpretable. If two global latent construction modes fail, a richer latent architecture must be separately licensed rather than silently absorbed into this phase.

## 4. M5-KRS-2MIX-CHAIN model

Let `D(x)=(K(x),R(x),S(x))` and retain exact training-only:

`q_d=P_train(D=d)`.

Let the hidden state be:

`Z in {0,1}`

with one **global** mixing probability:

`P(Z=1)=pi`, `P(Z=0)=1-pi`.

The mixing probability does not depend on K, R, S, slot position, leaf, line, or target quantities.

Within hidden mode `z`, define the same local family as Phase C:

`P_z(x | D=d) proportional to exp(sum_s h[z,s] U_s(x) + sum_s J[z,s] A_s(x))`

where:

- `U_s(x)=x_s`, `s=0..11`;
- `A_s(x)=x_s*x_{s+1}`, `s=0..10`;
- `h[z,0]=0` fixes the unary K gauge;
- `J[z,0]=0` fixes the adjacent K-R gauge.

The final conditional distribution is:

`P(x | D=d) = (1-pi) P_0(x|d) + pi P_1(x|d)`.

The full generated distribution is:

`P(x)=q_{D(x)} P(x|D(x))`.

## 7. Deterministic multi-start EM

The mixture likelihood is non-convex, so a prospective deterministic multi-start scheme is frozen here.

### 7.1 M3 baseline

### 7.2 Starts

- start `0`: `theta_0=theta_M3`, `theta_1=theta_M3`, `pi=0.5`;

### 7.3 Exact E-step

Compress the training corpus to exact counts of `(descriptor, 12-bit signature)`.

For every occupied training signature compute the posterior responsibilities exactly from:

`pi`, `P_0(x|d)`, and `P_1(x|d)`.

Use stable log-sum-exp arithmetic.

### 7.4 Exact M-step

Update:

`pi = total posterior mass of Z=1 / N_train`.

For each component separately:

- posterior-weight the empirical descriptor masses;
- posterior-weight the 21 free M3 sufficient statistics;
- solve the corresponding exact descriptor-conditioned exponential-family MLE with the deterministic Newton/damped moment solver;
- require max absolute component M-step moment error `<=1e-10`.

No pseudocount, prior, regularizer, temperature, or target-derived penalty is permitted.

A split start with component posterior mass `<1e-8 * N_train` is classified as a collapsed start and cannot be selected over a valid non-collapsed start. Start 0 remains a valid M3-equivalent baseline.

### 7.5 EM convergence

For each start:

- maximum `500` EM iterations;
- observed conditional log likelihood must not decrease by more than `1e-10` total log-likelihood units between accepted iterations;
- stop when per-token log-likelihood improvement is `<=1e-10` for two consecutive iterations;
- all probabilities and parameters must remain finite;
- no random restart or reroll on failure.

### 7.6 Training-only start selection

Among valid completed starts select exactly the one with the highest final **training conditional log likelihood**.

Tie rule:

1. larger log likelihood wins if difference exceeds `1e-10`;
2. otherwise smaller start index wins.

Target R1, held-out-fold R1, IT2a, or any target residual cannot participate in start selection.
