## 1. Scientific question

Phase D showed that generic nonadjacent coupling determined only by slot separation improves R1 only modestly (`median T_M4-T_M3 = +0.0212177060`) and remains far below the empirical complete-signature ceiling.

The next minimal mechanism is a hidden construction mode:

> **Can the replicated complete 66-edge topology be generated by a mixture of only two local K/R/S-conditioned transition grammars, with no explicit nonadjacent pair interaction at all?**

Mechanistic sequence:

1. draw coarse token geometry `(K,R,S)` from the training-only empirical distribution;
2. draw one hidden token-construction mode `Z in {0,1}`;
3. within that mode, generate the 12-slot occupancy pattern using only position-specific unary and nearest-neighbor terms.

Mixing two local grammars can induce long-range dependency because several distant slot preferences can change jointly with `Z`.

## 2. Why this model is deliberately minimal

Phase E tests **two** latent modes only. It does not simultaneously add:

- a third latent mode;
- K/R/S-dependent gating;
- explicit nonadjacent distance terms;
- named distant slot-pair interactions;
- signature-specific parameters;
- manuscript/line placement state;
- target-derived architecture changes.

A negative result therefore has a clear meaning: one global binary hidden mode is insufficient, without silently absorbing richer latent flexibility.

## 4. M5-KRS-2MIX-CHAIN model

Let `D(x)=(K(x),R(x),S(x))` and preserve exact training-only:

`q_d=P_train(D=d)`.

Let:

`Z in {0,1}`

with one **global** mixing probability:

`P(Z=1)=pi`, `P(Z=0)=1-pi`.

The gate is independent of K, R, S, slot position, leaf, line, and target quantities.

Within mode `z` use the Phase-C local family:

`P_z(x | D=d) proportional to exp(sum_s h[z,s] U_s(x) + sum_s J[z,s] A_s(x))`

where:

- `U_s(x)=x_s`, `s=0..11`;
- `A_s(x)=x_s*x_{s+1}`, `s=0..10`;
- `h[z,0]=0` fixes the unary K gauge;
- `J[z,0]=0` fixes the adjacent K-R gauge.

Final conditional distribution:

`P(x | D=d)=(1-pi)P_0(x|d)+pi P_1(x|d)`.

Full generated distribution:

`P(x)=q_{D(x)}P(x|D(x))`.

## 7. Deterministic exact-likelihood multi-start optimization

The mixture likelihood is non-convex, so the start population and optimizer are frozen prospectively.

### 7.1 M3 nested baseline

### 7.2 Parameterization

`v=(theta_0[21], theta_1[21], eta)`

where:

`pi=sigmoid(eta)`.

The objective and analytic gradient are computed from exact aggregated training signature counts and exact component descriptor normalizers.

### 7.3 Frozen starts

Run exactly **9** starts per cross-fit split:

- start `0`: `theta_0=theta_M3`, `theta_1=theta_M3`, `eta=0`;
- starts `1..8`: deterministic unit contrast vector `u_k` in 21 dimensions from namespace
  `issue75:phaseE:M5-KRS-2MIX-CHAIN:init{k}`;
- start `k=1..8`:
  - `theta_0=theta_M3 + 0.10*u_k`;
  - `theta_1=theta_M3 - 0.10*u_k`;
  - `eta=0`.

Exact seed-to-vector rule:

For coordinate `j=0..20`, compute SHA-256 of UTF-8 text

`issue75:phaseE:M5-KRS-2MIX-CHAIN:init{k}:coord{j}`.

Interpret the first 8 digest bytes as an unsigned big-endian integer `n`, map to

`a_j=((n+0.5)/2^64)-0.5`,

then set `u_k=a/||a||_2`.

This uses no pseudo-random library state and is platform-independent apart from ordinary IEEE-754 conversion. No additional start may be added after any Phase-E target result exists.

### 7.4 Exact likelihood and gradient

Compress the training corpus to exact counts of each non-empty 12-bit state.

For every descriptor and state, compute exact component probabilities:

`p_z(x|d)=exp(theta_z dot F(x))/Z_z(d)`

using stable log-sum-exp.

For each observed state define the exact mixture responsibility:

`r_1 = pi*p_1 / ((1-pi)*p_0 + pi*p_1)` and `r_0=1-r_1`.

The analytic score is:

- for `theta_z`: posterior-weighted empirical feature total minus posterior descriptor mass times exact component feature expectation;
- for `eta`: `sum_i (r_1(i)-pi)`.

The executable must finite-difference-check the analytic gradient at one fixed training-only synthetic parameter vector before fitting. Maximum relative/absolute discrepancy must be `<=1e-5`.

### 7.5 Optimizer

Use SciPy L-BFGS-B with:

- analytic gradient;
- `maxiter=2000`;
- `ftol=1e-12`;
- `gtol=1e-8`;
- no parameter bounds;
- no regularizer, prior, pseudocount, temperature, or target-derived penalty.

A start is valid if:

- objective and gradient remain finite;
- final `pi` is strictly between `1e-8` and `1-1e-8`, except start 0 may remain the exact M3-equivalent baseline at `pi=0.5`;
- final conditional log likelihood is finite;
- exact mixture normalization is within `1e-12` for every nonzero descriptor;
- optimizer either reports convergence or has infinity-norm analytic gradient `<=1e-6` at termination.

No failed start is rerun with a changed initialization. Start 0 must remain available as the nested M3 baseline.
