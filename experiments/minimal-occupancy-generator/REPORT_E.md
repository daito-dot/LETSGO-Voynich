# Issue #75 Phase E — two-mode latent-chain generator result

Date: 2026-09-02  
Status: **COMPLETE / FIRST-REVEAL AUTHORITY PERMANENTLY FROZEN**

## Primary question

Phase E asked whether the replicated complete 66-edge residual occupancy topology can be generated by a mixture of only **two global hidden token-construction modes**, when each mode itself uses only the already-supported local K/R/S-conditioned chain grammar.

The answer is:

> **Two latent local-chain modes recover a large additional fraction of the topology, but are not sufficient under the frozen M+ equivalence criterion.**

Frozen classification:

`M5_KRS_TWO_LATENT_CHAIN_MODES_INSUFFICIENT_RICHER_LATENT_OR_CONFIGURATION_RULE_REQUIRED`

This is a strong positive result for the *latent/common-cause direction*, but a negative result for the specific hypothesis that one global binary A/B construction state is enough.

## Model tested

`M5-KRS-2MIX-CHAIN`

Generation:

1. draw K/R/S from the training-only empirical distribution;
2. draw one global hidden construction mode `Z in {0,1}` with mixing probability `pi`;
3. conditional on Z, generate the 12-slot occupancy signature with only position-specific unary terms and nearest-neighbour interactions.

Each latent component is exactly the M3 local-chain family:

- 11 free unary terms;
- 10 free adjacent interaction terms;
- 21 continuous parameters per component;
- 2 components plus one global mixing probability;
- 43 continuous parameters per fold.

Explicit nonadjacent interactions: `0`  
Generic distance parameters: `0`  
Named distant-pair parameters: `0`  
Complete-signature-specific parameters: `0`

M3 is nested as the special case in which the two components coincide.

## Frozen fitting and selection

All fitting was target-blind and used training physical leaves only.

The non-convex mixture fit was prospectively frozen to:

- exactly 9 deterministic EM starts per fold;
- start 0 = M3-equivalent initialization;
- starts 1..8 = deterministic SHA-seeded symmetric perturbations;
- exact E-step;
- exact state enumeration over the 4095 non-empty occupancy signatures;
- exact exponential-family component M-steps;
- maximum 500 EM iterations;
- frozen component-collapse rule;
- best start selected by training conditional log likelihood only;
- deterministic label canonicalization;
- no random restart, reroll, target correlation, target residual, or held-out target edge used for model selection.

The target-blind fitted mixture itself was non-trivial:

- selected starts across the five physical folds: `2, 3, 2, 2, 3`;
- fitted `pi` values were approximately `0.485–0.505`;
- training conditional log likelihood improved over M3 by roughly `0.415–0.425 nat/token` across folds.

Thus the two-component decomposition was already strongly preferred by the training occupancy data before any target graph was opened.

## Mechanistic interpretation

Phase D showed that long-range dependence cannot be reduced to a generic function of physical slot separation.

Phase E adds a more specific result:

> **A common hidden construction state can generate a substantial amount of the observed long-range topology without any explicit long-range pair parameter.**

That is consistent with the idea that distant slots co-vary partly because they respond to the same token-level construction regime, rather than because every distant slot pair directly interacts.

However, one global binary state is too coarse. The remaining difference from M+ is still large.

The current supported decomposition is therefore:

`K/R/S coarse token geometry`

`+ local position-specific transition grammar`

`+ latent/common-cause construction variation   <-- strongly supported direction`

`+ richer latent/configuration structure        <-- still required`

`empirical complete signature inventory          <-- sufficient positive control`

## What Phase E rules out

Under the tested model family, the replicated 66-edge topology is not adequately explained by:

- one local transition grammar alone;
- that grammar plus generic physical-distance coupling;
- or a 50/50-ish mixture of only two global local-chain grammars whose mode prior is independent of K/R/S.

This does **not** imply that there are literally two or more semantic classes in the manuscript. The latent states are statistical construction states in the occupancy generator.

## Licensed next frontier

The frozen Phase-E failure licenses a richer latent/configuration test, but it does not license arbitrary complexity.

In particular it does not license:

- selecting individual distant slot pairs from the revealed target residuals;
- unrestricted 66-edge Ising fitting;
- choosing latent-state count from target R1 performance;
- target-driven parser/population/fold/null changes;
- semantic interpretation of latent components.

The next architecture must be justified and selected with training-only evidence and preregistered before its own target evaluation.

The most important unresolved mechanistic alternatives are now:

1. **geometry-conditioned mode choice** — the probability of entering a latent construction regime may depend on coarse token geometry such as K/R/S rather than one global `pi`;
2. **more than two global construction regimes** — a binary state may simply underresolve a multimodal inventory;
3. **within-token hidden-state evolution** — the construction state itself may change as the token is built, rather than being fixed globally for the whole token.

These alternatives should be discriminated using training physical leaves only before another target reveal.

## Relationship to Issue #72

Issue #72 localized the R1 information primarily to completed within-token occupancy configurations rather than exact plaintext local order or their placement across manuscript lines.

Phases A–E now further decompose that configuration information:

- marginal occupancy: insufficient;
- occupancy count: insufficient and can generate the wrong topology;
- coarse K/R/S shape: real but limited;
- local adjacency: strongly informative;
- generic distance: small additional contribution;
- binary latent local grammar: large additional contribution, still insufficient.

The research question has therefore narrowed substantially:

> **What compact latent construction process selects among the allowed 12-slot configurations?**

## Boundaries

Phase E does not establish:

- exactly two real Voynich construction modes;
- meanings for the latent states or slots;
- plaintext letters or words;
- a cipher table;
- natural-language morphology;
- a historical encoding procedure;
- Latin or any other plaintext language;
- decipherment.

It establishes that latent/common-cause structure is a productive mechanistic explanation for a substantial part of the independently replicated within-token occupancy topology, while a single global binary mixture remains insufficient.
