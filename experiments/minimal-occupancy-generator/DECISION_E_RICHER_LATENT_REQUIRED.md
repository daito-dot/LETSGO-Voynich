## Immediate next action

Before preregistering another target test, run a **target-blind training-only latent-frontier diagnostic** to distinguish at least these possibilities:

1. the two-mode prior is too simple because mode prevalence depends systematically on K/R/S;
2. two global modes are insufficient and a third mode produces reproducible cross-leaf likelihood gain;
3. neither global-mixture extension is adequate, motivating a within-token hidden-state mechanism.

The diagnostic must select by training physical-leaf predictive likelihood/complexity only. It must not read or score the Phase-E target residual vector.

Only after that diagnostic is frozen should the next target model be preregistered.
