# Phase 59 plan — mechanism discrimination on the audited state phenomena

Status: frozen before comparator scoring.

## Motivation

Phase58A found no simple location nuisance signal in the robust 2D residual. Phase58B found no page-level visual association in two matched domains. Phase58C cannot prospectively localize paragraphs to illustrated subobjects with the current independent annotations.

The next legitimate question is therefore mechanistic rather than semantic:

**Which known text-generation mechanisms reproduce the same combination of multiscale state phenomena?**

## Frozen target phenomena

No new target may be selected after comparator results are seen.

1. matched-window near-family/local-continuity latent axis;
2. paragraph-entry -> later-line multivariate transition;
3. page/paragraph local-state similarity;
4. stable leading residual subspace after broad metadata/context prediction;
5. modest generic short-range clustering rather than the excessive clustering produced by simple paragraph family generators.

## Comparator families

### N — meaningful prose
At least one paragraphized natural-language prose corpus. Start with the locally retained Dante control, then broaden when source-compatible corpora are available.

### C — bounded cipher transforms
Apply frozen transforms to the same prose so plaintext paragraph/content organization is retained while surface morphology is altered. Transform parameters must be fixed before scoring each comparator family.

### F — formal generators
Use previously frozen DSL/generator variants, especially the Phase51 insufficient simple DSL and any later generator only if its added mechanisms are explicitly complexity-charged.

## Primary evaluation

Run the same representation/matched-window pipeline as far as the comparator permits. Report a vector of target statistics; do not collapse to a single target-aware score until normalization and weighting are frozen.

A mechanism family gains support only if it reproduces the joint pattern without target-specific tuning.

## Hypotheses

### H59-N
Ordinary meaningful prose with paragraph structure naturally reproduces the Phase56/57 state geometry.

### H59-C
A bounded cipher transformation of meaningful prose reproduces the geometry materially better than plaintext alone.

### H59-F
A meaning-free hierarchical formal generator reproduces the geometry with comparable or lower complexity than the cipher/prose alternatives.

## Falsification logic

- If ordinary prose reproduces the joint pattern, the phenomena lose value as Voynich-specific mechanism evidence.
- If only bounded ciphers reproduce it, information-preserving encipherment gains relative support.
- If a compact formal generator reproduces it while prose/cipher do not, formal generation gains relative support.
- If none reproduce it, the comparator space is inadequate; do not infer a unique historical mechanism.

## First execution

Phase59A uses the retained Dante paragraph control as a pipeline sanity comparator. It is not sufficient alone for a natural-language-family conclusion.
